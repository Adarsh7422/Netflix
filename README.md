# Netflix
📊 Netflix Content Analysis Dashboard | Power BI
📌 Project Description

This project focuses on analyzing Netflix’s content library using Power BI to uncover patterns related to content distribution across countries, ratings, content types, and release years. The dashboard enables interactive exploration of the dataset through slicers and visuals to support data-driven insights for content strategy and regional analysis.

🛠 Tools & Technologies

Power BI

Power Query (Data Cleaning & Transformation)

DAX (Measures & Calculations)

Data Visualization

🔍 Key Highlights

Analyzed 5,000+ Netflix titles across multiple countries and years

Interactive filters for year, genre, and description

Country-wise and rating-wise content distribution analysis

Visual comparison of Movies vs TV Shows

Geographic visualization for global content spread

🎯 Objective

To build an interactive and insightful dashboard that helps stakeholders quickly understand content trends and make informed decisions regarding content acquisition and audience targeting.
